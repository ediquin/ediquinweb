My own project · Open source (MIT)

AI_design_7thday

Skills for Claude Code and Codex that design Youth Ministries posters, cards and certificates. They teach the assistant which emblem goes where, what each scarf looks like and what it must not make up.

  • afiches-iasd: high-resolution posters and certificate templates
  • cartillas-iasd: PDF cards with real spaces for QR stickers
  • reparar-simbolos-iasd: fixes only the emblem that came out wrong

Inside there is an ontology of symbols and rules (which emblem goes with each club and class) and a reference catalogue the agent checks before drawing.
